# PhoneWheel 帧协议（PWR1）

iPhone 伴侣 App ↔ Windows 插件之间的二进制协议。传输层为 TCP over usbmux（`iproxy` 端口转发），小端字节序。WiFi UDP 模式复用同一编解码（UDP 报文即一帧）。

## 1. 帧头（20 字节，所有帧通用）

| 偏移 | 字段 | 类型 | 说明 |
|------|------|------|------|
| 0 | magic | `char[4]` | 固定 `"PWR1"`（0x50 0x57 0x52 0x31） |
| 4 | version | u8 | 协议版本，当前 = 1 |
| 5 | flags | u8 | 位标志，见下 |
| 6 | payloadLen | u16 | 载荷字节数（0–1024） |
| 8 | seq | u32 | 发送端递增序号（每端独立） |
| 12 | tSend | i64 | 发送时刻，微秒（手机端单调时钟；PC 端命令帧填 0） |

**flags 位定义**：

| 位 | 值 | 含义 |
|----|----|------|
| bit0 | 0x01 | 命令帧（PC → 手机） |
| bit1 | 0x02 | Hello 握手帧 |
| bit2 | 0x04 | Keepalive 心跳（payloadLen = 0） |
| bit3 | 0x08 | 错误帧（载荷 = u16 错误码） |
| bit4 | 0x10 | 校准请求（手机 → PC，payloadLen = 0；PC 用最近一帧姿态重置水平中位） |

## 2. 运动帧（手机 → PC，100Hz，payloadLen = 45）

| 偏移 | 字段 | 类型 | 说明 |
|------|------|------|------|
| 0 | qx | f32 | 姿态四元数 x（设备坐标系 → 参考坐标系） |
| 4 | qy | f32 | 同上 |
| 8 | qz | f32 | 同上 |
| 12 | qw | f32 | 同上 |
| 16 | gx | f32 | 设备系重力分量 x（单位 g） |
| 20 | gy | f32 | 同上 |
| 24 | gz | f32 | 同上 |
| 28 | rx | f32 | 设备系角速度 x（rad/s） |
| 32 | ry | f32 | 同上 |
| 36 | rz | f32 | 同上 |
| 40 | throttle | u8 | 触摸油门 0–255 |
| 41 | brake | u8 | 触摸刹车 0–255 |
| 42 | buttons | u16 | 按钮位标志，见下 |
| 44 | battery | u8 | 电量 0–100 |

**buttons 位定义**：

| 位 | 名称 | 虚拟手柄 |
|----|------|----------|
| 0 | ShiftUp 升挡 | RB |
| 1 | ShiftDown 降挡 | LB |
| 2 | Handbrake 手刹 | A |
| 3 | LookLeft 视角左 | X |
| 4 | LookRight 视角右 | B |
| 5 | Menu 菜单 | Start |
| 6 | View 返回 | Back |
| 7 | ResetCar 重置车辆 | Y |
| 8–15 | 预留 | — |

## 3. 命令帧（PC → 手机，payloadLen = 5）

| 偏移 | 字段 | 类型 | 说明 |
|------|------|------|------|
| 0 | cmd | u8 | 1 = 短震；2 = 持续震动；3 = 停止 |
| 1 | intensity | u8 | 强度 0–100 |
| 2 | durationMs | u16 | 持续时长 ms（cmd=2 有效） |
| 4 | reserved | u8 | 0 |

## 4. Hello 握手帧（flags = 0x02）

任一端连接建立后发送；载荷：

| 偏移 | 字段 | 类型 | 说明 |
|------|------|------|------|
| 0 | appVersion | u8 | 应用版本 |
| 1 | protoVersion | u8 | 协议版本（必须 = 1） |
| 2 | deviceModelLen | u8 | 设备型号字符串长度 |
| 3 | deviceModel | char[n] | 如 "iPhone15,2" |

对端 `protoVersion != 1` → 回复错误帧（错误码 1）并关闭连接。

## 5. 错误码（错误帧载荷，u16）

| 码 | 含义 |
|----|------|
| 1 | 协议版本不支持 |
| 2 | payloadLen 非法（> 1024 或与帧类型不符） |
| 3 | 帧头魔术不匹配 |
| 4 | 看门狗超时（PC 侧状态帧，诊断用） |

## 6. 连接状态机

```
连接建立
  → 双方发送 Hello（版本协商）
  → 手机 100Hz 发送运动帧；500ms 无运动帧则补发 Keepalive
  → PC 需要触觉时发送命令帧
  → TCP 断开 / 看门狗 200ms 超时：PC 端虚拟手柄回中熄火，监管层重连
```

## 7. 设计约定

- **实时流语义**：收端只消费最新帧，seq 仅用于乱序/丢包统计，不做重传；
- **帧率与带宽**：100Hz × 65B ≈ 6.5KB/s，USB 本地回环无压力；
- **前向轴约定**：手机"12 点方向"默认 = 设备系 +Y（横屏顶部朝前），PC 端 `steering.forwardAxis` 可改；
- **参考系约定**：`.xArbitraryZVertical`，参考系 Z 轴恒为重力反向（世界上轴），PC 端据此做水平投影。
